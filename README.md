# Daily Dose website

Hosts the Daily Dose privacy policy on GitHub Pages.

- Home: `index.html`
- Privacy policy: `privacy/index.html` → served at `/privacy/`

## Before publishing
Replace `[YOUR CONTACT EMAIL]` in `privacy/index.html`.

## Turn on GitHub Pages
1. Create a **public** repo (for example `dailydose`) and upload these files, keeping the `privacy` folder.
2. Repo **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, folder **/ (root)** → Save.
3. After a minute the site is live at `https://<your-username>.github.io/dailydose/`.
4. Paste `https://<your-username>.github.io/dailydose/privacy/` into App Store Connect's Privacy Policy URL.
